# Refonte — captures avant / après

- `BRIEF.md` : brief de design (référence, polices, palette, grille, mouvement).
- `avant/` : chaque page avant la refonte.
- `apres/` : les mêmes pages après la refonte (et avec le calendrier « Perso »).

Nom des fichiers : `<page>-<ordinateur|telephone>-<clair|sombre>.jpg`. Pages : accueil, projets, projet (éditeur), notions, notions-gerer, memo, newsletters (non configuré), news, favoris, revue, palette (⌘K), calendriers (fenêtre « Gérer les calendriers »).

Toutes les captures utilisent des **données de démonstration** (titres « Démo — … », images abstraites générées) : aucun contenu personnel ni image d'un site tiers.
